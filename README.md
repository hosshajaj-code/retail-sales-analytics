# Retail Sales Analytics & Executive Dashboard

An end-to-end retail data analytics project built to analyze sales, profitability, customers, and business performance using **Python, SQL, EDA, and Power BI**.

##  Tech Stack

* Python & Pandas
* SQL
* Exploratory Data Analysis (EDA)
* Power BI
* DAX
* Power Query
* Data Modeling

##  Key KPIs

* Total Sales
* Total Profit
* Total Quantity
* Average Order Value (AOV)
* Profit Margin %

##  Dashboard Features

* Sales by Category
* Sales by Customer Segment
* Top Customers
* Sales Trends
* Regional Analysis
* Interactive Filters

##  Workflow

**Python → SQL → EDA → Business Insights → Power BI**

##  Objective

Transform raw retail transaction data into clear business insights and an interactive executive dashboard to support data-driven decision making.
